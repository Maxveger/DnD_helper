# Продолжение работы

Обновлено 2026-09-16. Начинать с [основы проекта](PROJECT_BRIEF.md): нужен помощник начинающему ведущему живой настольной группы. Техническое название «свободный мир» не означает самостоятельную одиночную игру.

## Сделано в текущих исходниках

- Один запрос Luna на карточку ведущего, включая обе ветки броска; нет обязательного критика и рассказчика.
- Отдельные заявка игрока и вопрос ведущего, выбор героя, короткий совет, редактируемый черновик, основания и явный расчёт последствий.
- Локальные известные переходы, броски, подтверждение, правки, запись ведущего и отмена.
- Свои сценарии/лор `dnd-world@1`, комплект для GPT, локальная проверка с рекомендациями, журнал `dnd-world-log@1`, восстановление и продолжение.
- Проверки с настоящей Luna: карточки 8,5–14,4 с в короткой выборке; сохранение обещания после загрузки, второй герой, импровизация, рисковый бросок, знания NPC. Найденные смысловые ошибки и пределы проверки отражены в [отчёте](GM_ASSISTANT_CHECK.md).
- Прежние подготовленные приключения и их исправления интерфейса сохранены. Пользовательские игры не используются для тестов.

## Дальше — в порядке пользы

1. **Живой прогон за столом 30–40 минут.** Ведущий и 1–2 игрока; оценить, помогает ли карточка новичку, какие подсказки приходится исправлять и где возникает пауза. Измерять не только время ответа, но и время на понимание карточки.
2. По результатам улучшить ручное управление механикой, групповые заявки и ситуации боя. Пока одна карточка относится к одному действующему герою, дополнительные действия разбирает ведущий.
3. Проверить длинную партию и рост контекста. Приложение хранит все факты текущего короткого мира, но качество модели на длинной игре не подтверждено.
4. Перед передачей обновить GitHub/Windows-пакет и пройти установку/вход на ноутбуке ведущего. Опубликованный `v0.1.0-rc.1` нового подсказчика не содержит.
5. Подключать Telegram/голос только как отдельные адаптеры после текстового прогона. Текущий ответ содержит секреты ведущего и не может автоматически пересылаться игрокам. Распознавание речи — отдельный API.

Остаёмся на дешёвой Luna и собственном входе оператора через Codex. Альтернативный API с потолком $5 не включается автоматически. Изменение модели или добавление запросов требует измерений; не возвращать ожидание трёх запросов на каждый ход.

## Запуск

```bash
./start.sh --data-dir ./data
```

Открыть «Помощник ведущего». Для чистых экспериментов указать отдельный каталог данных. Не отменять и не переигрывать текущую пользовательскую карточку ради теста.
