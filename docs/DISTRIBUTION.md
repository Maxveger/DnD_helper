# Поставка

Текущая цель — локальная Windows-сборка одного приложения `/studio`. Codex CLI устанавливается и авторизуется отдельно; его токены не входят в пакет.

```bash
uv run --frozen python scripts/build.py
uv run --frozen python scripts/smoke.py --executable dist/DnD-Helper/DnD-Helper.exe
```

Перед публикацией нужны Windows-проверка входа Codex и законченная живая партия. Старый `v0.1.0-rc.1` не является кандидатом текущего продукта.

Для будущей закрытой альфы выбран ноутбук владельца + приватный Tailscale Serve, один тестировщик за раз и отдельный каталог данных на прогон. Публичную VM и Funnel не использовать без нового решения.
