# Основа проекта

Приложение помогает начинающему человеку вести настольную игру для 3–4 игроков. Модель импровизирует мир, NPC, проверки и последствия, но не становится автономным ведущим: человек видит закрытые основания, редактирует реплику и подтверждает канон.

## Текущий продукт

- Единственный интерфейс — локальная игровая IDE `/studio`.
- Один игровой модельный тред обеспечивает живую связность; локальная капсула и принятый диалог остаются авторитетом.
- Один запрос готовит карточку и обе ветки броска. Кубик и выбор ветки выполняются локально.
- `Совет` и `Мета` приватны и не меняют канон.
- Независимый редактор оценивает текущую непринятую карточку в фоне. Только решение ведущего запускает её одноразовую пересборку игровой моделью.
- По умолчанию используется Luna через официальный Codex CLI и личную подписку. Платного API и автоматического fallback нет.

Сейчас встроен только лабораторный срез «Сайрус → Дом → Око». Он проверяет опыт и границы доверия, а не формат будущих сценариев. Пользовательские сценарии, импорт и экспорт будут спроектированы заново после успешных длинных прогонов; старые схемы и движки не являются совместимым фундаментом.

## Приоритет

Чистый прогон от задания Сайруса до Ока подтвердил строгую игру. Следующие прогоны показали, что одной редакторской страховки мало: игровой слой дробил ожидание и реакции NPC на ходы без решения. Теперь каждый исход обязан довести заявку до явной передачи управления, а динамическая ситуация заменяется целиком. Следующий эксперимент должен проверить этот контракт вживую; метаслой остаётся редактором открытой карточки.

Нельзя возвращать несколько последовательных моделей на пути игрового ответа, каталоги правильных действий, векторную базу, Telegram, голос или публичный сервер до отдельного решения.
