# Сторонние компоненты

Приложение использует Python, FastAPI, Uvicorn и Pydantic. Для разработки применяются pytest, Ruff, Playwright и PyInstaller. Codex CLI — отдельная пользовательская установка и не входит в дистрибутив.

У проекта пока не выбрана собственная лицензия; публичную поставку до этого не выпускать.
