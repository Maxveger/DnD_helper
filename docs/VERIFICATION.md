# Проверки

Актуальный исполняемый продукт — только `/studio`.

Проверяются:

- 35 модульных контрактов Studio и CodexProvider;
- Python и JavaScript синтаксис;
- настоящий локальный HTTP-запуск на временной базе, повторный запуск и сохранение Studio;
- изолированный браузерный путь 1366×768 с подставной моделью, включая игровой ход, Совет и «Пульс игры».

После удаления старых режимов полный оставшийся набор, Ruff, `node --check`, `git diff --check`, Studio-only HTTP smoke и браузерный сценарий прошли на Linux. Smoke отдельно проверяет, что корень больше не открывает удалённое демо.

Во втором живом прогоне модель вернула для проверки пустой читаемый текст и дельту, не фиксирующую уже совершённый выход героя. Шаг был штатно отменён. Схема теперь запрещает пустой исход, обе ветки проверки обязаны менять положение или память, а принятие пустого текста блокируется отдельно. Эти контракты покрыты модульными тестами; повтор спорной заявки живой модели ещё предстоит.

Обычные тесты не используют подписку. `scripts/studio_probe.py` — отдельная живая проба и должна запускаться сознательно.

Живой прогон после очистки дошёл от Сайруса до Ока: 31 принятое событие, 32 игровых и 8 режиссёрских вызовов, все технически успешны. Пользователь не заметил регресса и признал пассивный мета-слой уместным. Коррекции наблюдателя намеренно не применялись.

Ещё не подтверждены живой прогон с сознательным выбором режиссёрских коррекций, длинная партия, Windows-сборка текущего среза и пользовательские сценарии.
