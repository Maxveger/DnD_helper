# Что проверено

[← Путеводитель](README.md) · [Экран для начинающего ведущего](UI_READABILITY.md) · [Передача приложения ведущему](DISTRIBUTION.md)

Сводка на **2026-09-21**. Активный эксперимент `/studio` использует одну ограниченную живую беседу, авторитетную локальную память и подтверждение ведущего. Два пользовательских прогона дошли до Ока; это промежуточный успех лабораторного среза, а не приёмка полной партии.

## Текущая проверка разговорного режиссёра

- Прошли **190** автоматических тестов. Семь тестов со встроенным `TestClient` сознательно исключены из этого запуска из-за прежнего зависания адаптера на lifespan в окружении; это не заявление об их успехе.
- Проверены: эфемерный вызов без `resume`; компактная папка без полного документа и журнала; разделение физически представленных, известных удалённых и ещё не введённых сущностей; рамки сцен и их валидация; вывод авторской возможности при пустом осмотре и неокончательной неудаче; закрытые маршруты; очистка старого броска после пересборки; предусловия переходов; авторская проверка вместо модельной; старые гарантии транзакций, финалов, журнала и импорта.
- Ruff прошёл для изменённых Python-файлов и тестов; `node --check dnd_helper/static/world.js` прошёл.
- Smoke-прогон на одноразовой базе прошёл реальный HTTP-запуск, перезапуск, защиту от второго экземпляра, импорт и штатное завершение.
- Изолированный браузерный прогон через настоящий локальный HTTP-сервер, системный Chrome, временную базу и подставную модель прошёл прежний путь ведущего, сохранение режиссёрского указания, `present`, пересборку карточки, журнал и ширину 390 px.
- Отдельный браузерный прогон `/studio` на временной базе прошёл живую сессию, принятие карточки, приватный Совет, напоминание досье, сброс модельной беседы и фиксированную компоновку 1366×768 с независимыми полосами прокрутки.
- Второй живой прогон `/studio`: 21 принятый ход, 21 успешный модельный ответ, 0 форматных отказов; медиана ожидания 20,53 с. Пользователь дошёл до Ока и полностью удовлетворён поведением модели.
- Новый App Server проверен подставным процессом и живой Luna: один процесс обслужил несколько ходов одного треда, схема применялась каждый ход, зафиксированы первое событие/первый текст/полное время. Финальная короткая проба дала 9,73 с и 3,92 с для двух последовательных ответов; это не полная партия и не статистика p50.
- Операционная дельта капсулы прошла локальные проверки, браузерный smoke и живой ответ. Настоящее сжатие треда сработало, но на короткой истории заняло около 32 с и не сократило следующий вход; поэтому оно ограждено порогами длинного контекста.
- Реальная Luna продолжила короткую неинтерактивную сессию и вспомнила якорь первого запроса. Первый запрос: 2&nbsp;547 входных токенов, 4,51 с; второй: 5&nbsp;155 входных, кэш 0, 8,21 с.
- Два реальных хода учебного мира в одной сцене вернули готовые карточки без ремонта. Первый: 9&nbsp;257 входных, 14,22 с; второй: 21&nbsp;414 входных, из них 8&nbsp;960 кэшированных, 16,93 с.
- Локальная папка «Ока» для двух контрольных заявок занимает 11&nbsp;051 и 12&nbsp;544 символа данных; схема ответа — около 6&nbsp;095 символов. Это размер сериализации, не usage модели.
- На локальной копии «Ока» переход взгляда скрыт до состояния `idol=exposed` и местоположения Иво у реликвария; действие с поддельной печатью получает объявленный вариант `mind/standard`.
- Попытка отправить пользовательскую копию «Ока» во внешнюю живую пробу была остановлена из-за границы приватности. Полный сценарий должен проверяться только в явном пользовательском игровом запуске.

Полноценная партия и Windows не проверены. Подробная история — в [журнале решений](ENGINE_DESIGN_LOG.md).

**Предыдущая живая проверка опровергла накопительный путь.** Короткий прогон использовал 1 802 540 входных токенов; `resume` достиг 291 721 токена на одно обращение. В игре также произошли утечка тайны NPC, двойной отказ штатного перехода и фиктивный финальный бросок. Эти числа относятся к удалённой реализации, а не к текущему независимому запросу.

## Воспроизвести локально

Из корня проекта с установленными зависимостями:

```bash
uv run --frozen pytest -q
uv run --frozen ruff check dnd_helper tests scripts
node --check dnd_helper/static/world.js
node --check dnd_helper/static/studio.js
node --check dnd_helper/static/app.js
uv run --frozen python scripts/smoke.py
```

Установленная пара Starlette 1.6/httpx 0.28 даёт два предупреждения об устаревающем `TestClient`; тесты проходят. Позже тестовый адаптер следует обновить, но на работу локального сервера это предупреждение не влияет.

Текущий браузерный прогон сам поднимает изолированное приложение и использует тестового провайдера:

```bash
uv run --frozen playwright install chromium
PYTHONPATH=. uv run --frozen python scripts/browser_world_check.py
PYTHONPATH=. uv run --frozen python scripts/browser_studio_check.py
```

Команда с `PYTHONPATH=.` выше предназначена для Linux. В PowerShell перед запуском скрипта задайте `$env:PYTHONPATH = "."`. Node.js нужен только для приведённой проверки синтаксиса, не для веб-сборки.

Изолированные проверки подготовленного режима:

```bash
uv run --frozen python scripts/browser_import_check.py
uv run --frozen python scripts/browser_gameplay_check.py
```

`scripts/browser_check.py` принимает URL уже работающей установки и создаёт игру: указывать только **тестовый** сервер с отдельным `--data-dir`. Пользовательские сохранения не использовать.

## Живые пробы — отдельный запуск

Они обращаются к собственной авторизованной CLI-установке и расходуют лимит подписки. Обычные тесты выше этого не делают.

```bash
PYTHONPATH=. uv run --frozen python scripts/gm_assistant_probe.py --codex /path/to/codex --suite prose --output /tmp/gm-prose.json
```

Наборы `core`, `edges`, `prose` предназначены для разных коротких случаев. Не выдавать суммарное число изолированных проб за последовательную игровую сессию. Ошибки текста и соответствия операций фиксируются вместе с успешными случаями.

## Ещё не подтверждено

- Длинная щадящая партия в новом мире и отдельные стресс-тесты свободы действий.
- Живая партия 90–120 минут с 3–4 новичками и понятность интерфейса для начинающего ведущего.
- Качество длительного давления и нескольких конфликтов на настоящей модели; совместная заявка, обычная неудача и победный финал измерены, но это изолированные пробы, не приёмка партии.
- Обновлённый пакет на Windows и вход Codex на ноутбуке ведущего.
- Полный пользовательский цикл создания собственного мира в браузерном GPT.
- Реальные Telegram, GPT API и голосовые прежнего режима с ключами; для нового режима эти адаптеры ещё не подключены.

[Windows workflow](../.github/workflows/check.yml) проверяет тесты и упаковку, браузерные сценарии подготовленных приключений. Браузерный `/world` пока не включён в workflow: его успешный локальный прогон нельзя называть результатом Windows CI.
