# Проверка первой реализации

Дата: 2026-09-15. Среда: Linux x86_64, Python 3.12.13. Ключи GPT и Telegram не использовались.

## Выполнено

- **74 автоматических теста:** игровые правила, мирный финал для одного/двух игроков, успех и провал, бой, поражение, помощь, лечение, очередь, паузы и фазы запросов, сохранение и отмена, атомарный откат, повторные и конкурирующие команды, роли и приватность, устаревшие ответы, смена правил, бюджет, HTTP-ошибки и конвертация аудио.
- **Проверка стиля Python:** `ruff check dnd_helper tests scripts`.
- **Синтаксис JavaScript:** `node --check dnd_helper/static/app.js`.
- **Браузер Chromium:** создание группы, проверка с физическим числом, открытие улик, очистка фильтра, мирное получение сердечника, запуск насоса и завершение. После обновления страницы финал сохраняется, журнал доступен.
- **Размеры экрана:** 1440 px и 390 px; нет горизонтального переполнения, меню на узком экране открывается.
- **Настоящий локальный сервер:** запуск, один игровой шаг, повторный запуск без второго экземпляра, завершение и восстановление в каталоге с пробелами и кириллицей.
- **PyInstaller на Linux:** пакет собран; тот же smoke-сценарий выполнен через упакованный файл, без обращения к исходникам для запуска приложения.
- **Документация:** локальные ссылки проверены. Исходники архивируются отдельно от ключей и игровых данных.

В тестах HTTP-ответы OpenAI/Telegram подставные. Аудиоконвертер запускается настоящий; распознанный текст в тесте возвращает заглушка. Это проверяет сборку запроса и обработку результата, но не качество распознавания русского голоса.

Два предупреждения тестовых библиотек относятся к устаревающим интерфейсам Starlette/HTTPX и AnyIO. Проверки проходят; это не подтверждение совместимости с будущими версиями. Зависимости фиксируются в `uv.lock`.

## Импорт приключений: дополнительная проверка

- Валидатор `dnd-adventure@1`: типы, версии, неизвестные операции, ссылки, условия, ограничения размера, повреждённый JSON, дубли ключей, ручные правила и текст для исправления в чате.
- Библиотека: повторный импорт, новый документ с прежним номером версии, неизменность активной игры, переключение обратно на встроенную историю.
- Отдельная история «Последний сигнал»: свои герои/характеристики, d6, успех и неудача, предметы, лечение, условные переходы, бой через переменную, два финала, отмена и восстановление после перезапуска. Проверена группа до шести героев.
- Приватность: классификатор получает каталог текущей сцены без секретов; Telegram использует импортированные характеристики и кубик. Длинные публичные сообщения разбиваются на части без потери текста.
- Настоящий Chromium: скачивание задания, ошибка импорта, загрузка файла, добавление в библиотеку, выбор персонажа, провал проверки, лечение, развилка переходов, финал, обновление страницы и ширина 390 px.
- Тот же браузерный прогон и HTTP smoke прошли на **собранном Linux-приложении**. Промпт и пример присутствуют внутри пакета.
- Старая водокачка повторно пройдена через браузер после изменения интерфейса.
- Windows workflow расширен: после сборки exe предусмотрен браузерный прогон импортированного приключения. Workflow ещё не выполнялся на GitHub.

Авторский промпт подготовлен, но реальный цикл генерации документа в браузерном чате GPT человеком пока не пройден. Проверка структуры не доказывает проходимость всех условных веток, баланс или отсутствие смысловых противоречий.

## Предстоит проверить с ключами и целевой машиной

- Реальное подключение Telegram, приглашения и сообщения с телефонов.
- Доступность выбранных моделей на аккаунте, качество русского текста, имена персонажей, фактическая задержка и стоимость GPT.
- Windows-сборку из GitHub Actions и запуск на Windows 10/11. Linux-пакет не является Windows-приложением.
- Живую игру на 30–40 минут с начинающим ведущим: понятность подсказок и темп.

## Следующие функциональные улучшения

- Импорт экспортированного сохранения через интерфейс; сейчас есть экспорт и восстановление из локальной базы.
- Более свободная импровизация NPC и разбор сложных совместных действий. Сейчас GPT выбирает из подготовленного каталога, а неподдерживаемые случаи передаются ведущему.
- Дополнительные исполнители сложных систем правил, автоматическая проверка проходимости условных веток и редактор документов. Выбор/импорт приключений уже реализован.

Отчёт описывает реально выполненные проверки и не означает прохождения всех критериев целевого ТЗ на пользовательских устройствах.
