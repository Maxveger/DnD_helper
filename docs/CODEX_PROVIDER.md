# Codex в игровой IDE

Codex устанавливается отдельно. Приложение требует CLI 0.154.0+ и личный вход через ChatGPT, не копирует токены в базу и не переключается на платный API. По умолчанию выбрана Luna.

Studio лениво запускает два независимых `codex app-server --stdio`:

- игровой сервер продолжает строгий тред `Иво`/`Совет`/`Мета`;
- режиссёрский сервер продолжает приватный тред наблюдателя и может работать во время инициативы игроков.

Первый игровой запрос получает роль, досье, капсулу и принятый диалог. Продолжения получают новую реплику и авторитетные решения ведущего. Наблюдатель получает досье один раз, затем текущую капсулу и новые принятые события. Полная схема результата применяется каждый ход, но неизменное досье не повторяется.

Инструменты, веб, плагины и делегирование выключены. Вывод проверяется Pydantic и локальным игровым кодом. Тайм-аут — 120 секунд; отмена использует `turn/interrupt`. При остановке приложения завершаются обе группы процессов.

Диагностика хранит время до первого события, первого текста и завершения, а также usage конкретного хода. Наблюдатель помечен как `director`, поэтому его стоимость видна отдельно. Подписочные токены не переводятся в деньги, остаток лимита приложение не угадывает.

Подставные процессы проверяют продолжение треда, схему, потоковые метрики, ошибки, отключение инструментов и сжатие. Живой игровой App Server проверен короткими пробами; живой второй сервер наблюдателя ещё предстоит проверить от задания Сайруса.
