# Первый запуск

## Готовый пакет Windows

1. Скачайте архив Windows из выпуска проекта и полностью распакуйте его.
2. Запустите `DnD-Helper.exe`. Не переносите его отдельно от папки `_internal`.
3. Откроется браузер. Нажмите «Собрать группу», выберите одного или двух героев.
4. Оставьте «Демо» для проверки без Telegram и ключей. Нажмите «Начать приключение».

Установка Python, Git, Docker и Node.js для готового пакета не нужна. Если доступен только исходный код, сначала выполните инструкцию разработчика из README.

## Пробная игра без ключей

Нажимайте готовые действия внизу экрана. Для проверки с кубиком выберите «Осмотреть насос», запросите бросок и нажмите «Ввести бросок». Можно бросить в приложении либо указать выпавшее на настоящем d20 число.

После результата нажмите «Продолжить». Для перехода между приёмной и мастерской используйте «Сменить локацию». Попробуйте договориться с Адой, забрать сердечник и починить насос. Если не знаете, что сказать, откройте «Только для ведущего» и «Помоги продолжить».

В деморежиме свободный текст распознаётся по небольшому словарю. Для неожиданного действия выберите подходящий тип в «Я отвечу сам / исправить действие» или опишите собственный исход. Это не результат работы GPT.

## Свой сценарий

Откройте **«Мои сценарии»**, скопируйте промпт в браузерный чат GPT и обсудите игру. По команде «Собери документ» чат выдаст JSON. Вставьте его в приложение или загрузите файл, проверьте и добавьте в библиотеку. Если найдены ошибки, скопируйте задание на исправление в тот же чат и повторите загрузку. Затем нажмите «Играть» у нужного приключения.

Правила, выполняемые только вручную, показаны до импорта и в памятке. Свои сценарии работают и в деморежиме без ключей. Начните с кнопки «Открыть пример» — отдельной истории про космическую станцию. [Подробности](ADVENTURE_FORMAT.md).

## Подключения

1. Откройте «Подключения» в левой панели.
2. Вставьте отдельно полученные ключ OpenAI API и токен Telegram-бота.
3. Включите нужные сервисы и сохраните. Необязательно включать их одновременно.
4. Дождитесь статуса Telegram «Подключён».
5. Создайте игру со снятой отметкой «Демо». Откройте «Пригласить игроков», передайте игрокам их ссылку. Свою ссылку ведущего откройте сами.
6. Дождитесь выбора персонажей и начните игру. Игроки пишут или отправляют голосовые в личный чат бота.

Голосовые распознаются через API. Без API можно отправлять обычный текст. Для физических кубиков игрок нажимает «Настоящий кубик» и отправляет выпавшее число. У каждого персонажа своя карточка в меню бота.

Кнопка «GPT включён» означает сохранённую настройку; реальная доступность модели подтверждается только успешным запросом. Стоимость зависит от провайдера и модели. Отображаемый расход включает консервативные оценки распознавания и запросов с неизвестным usage; это не банковский счёт.

## Сохранение и завершение

Изменения сохраняются автоматически. Закрытие вкладки не останавливает бота; используйте «Завершить приложение». При следующем запуске игра восстановится.

Каталог данных по умолчанию:

- Windows: `%LOCALAPPDATA%\DnDHelper`.
- Linux: `${XDG_DATA_HOME:-~/.local/share}/dnd-helper`.

Внутри: `game.sqlite3`, `settings.local.json`, папка `backups`. В `settings.local.json` находятся ключи — его передают отдельно и не добавляют к исходникам. Экспорт из журнала не содержит ключей и Telegram-привязок; файл экспорта пока предназначен для просмотра и передачи, автоматического импорта в этой версии нет.

Для обновления завершите приложение, распакуйте новую сборку и запустите её. Данные хранятся отдельно. Перед новой игрой и при завершении приключения создаётся резервная копия базы.

## Если что-то не работает

- Нет ответа бота: проверьте интернет, настройку Telegram и отсутствие другого запущенного экземпляра с тем же токеном.
- Уже настроен webhook: используйте отдельного бота для тестов; приложение не отключает чужую конфигурацию автоматически.
- Ошибка GPT: сохранение не потеряно, готовые действия и ручные исходы доступны.
- Непонятное действие: исправьте его тип или задайте результат сами. Приложение не должно придумывать недостающие правила.
- Истёк бюджет: продолжите с готовыми подсказками либо измените лимит в настройках.

Windows-пакет создаётся workflow проекта на Windows. Проверка на конкретном ноутбуке с Windows 10/11 остаётся отдельным этапом перед передачей.
