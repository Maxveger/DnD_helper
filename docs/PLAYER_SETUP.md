# Первый запуск

1. Установите официальный Codex CLI 0.154.0+ и выполните `codex login` через ChatGPT.
2. Запустите `start.cmd` на Windows или `./start.sh` на Linux.
3. Откроется игровая IDE. В «Настройки» проверьте вход и оставьте Luna, если нет причины менять модель.
4. Нажмите «Начать лабораторную сцену».

Игровой текст — черновик для ведущего. До подтверждения он не меняет память. «Совет» и «Мета» видит только ведущий. «Пульс игры» предлагает режиссёрское решение, но ничего не применяет сам.

Данные находятся в системном каталоге `DnDHelper`; для отдельной проверки используйте `--data-dir`. Не передавайте другим людям базу: в ней есть закрытая информация ведущего.
