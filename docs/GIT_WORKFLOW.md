# Git

Работайте короткими ветками и оставляйте коммиты в проверяемом состоянии. Базы, `runtime.json`, авторизация Codex, логи пользователей, `build/` и `dist/` не коммитятся.

Отвергнутые движки не хранятся рядом с текущим кодом «на всякий случай»: для восстановления существует история Git. Перед коммитом запускаются тесты, Ruff, `node --check` и `git diff --check`.
