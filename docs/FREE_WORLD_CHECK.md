## Что работает

В основном меню появилась ссылка **«Свободный мир»** (`/world`). В этом режиме доступны текстовое действие, трактовка моделью, проверка операций, выборочная смысловая проверка, бросок при риске, отдельная публичная реплика и принятие исхода ведущим. До принятия игровое состояние не меняется. Есть отмена заявки, ограниченный повтор после ошибки, отмена принятого хода и восстановление после перезапуска.

Начальная область — площадь, мастерская и лесная тропа; герой — Мира, NPC — Ада. Модель может добавлять связанные места, NPC, предметы, факты и обещания. Действия не выбираются из старого каталога. Предложения проверяются кодом; изменения, кроме обычного перехода героя между соседними известными местами, дополнительно проверяются моделью, если у них есть операции.

SQLite хранит мир, знания, события, неподтверждённое предложение и журнал вызовов. База `free-world.sqlite3` находится рядом с прежней `game.sqlite3`; демопартия сохраняется отдельно. Новый сеанс сохраняет предыдущую короткую игру в служебной записи базы; интерфейса её восстановления пока нет.

## Подключение ведущего

1. Установить официальный [Codex CLI](https://developers.openai.com/codex/cli), версия 0.154.0 или новее. Совместимость фактически проверена на 0.154.0.
2. Запустить приложение и открыть «Свободный мир».
3. Нажать **«Войти через ChatGPT»**, завершить штатный вход в своём аккаунте с доступом к Codex, затем **«Проверить вход»**. Если браузер не открылся, выполнить `codex login` в терминале.
4. Начать короткую игру, ввести действие и дождаться предложения. Для применения нажать **«Принять исход»**; перед броском показаны обе ветки.

Пароль, OAuth-токены и API-ключ для этого режима приложение не принимает и не копирует. Оно проверяет вход через CLI. Вход с API-ключом не разрешает подписочный режим. Модель выбирается в приложении; по умолчанию Luna. При явном выборе «Из настроек Codex» используется поле `model` пользовательского конфига или штатная модель CLI. Модель фиксируется на ход; остальной пользовательский конфиг при генерации не загружается. Автоматического перехода на API нет.

В текущем Linux-окружении уже выполнен вход через ChatGPT и выбран `gpt-6-astra`. Старый системный CLI 0.116.0 не поддержал эту модель, поэтому 0.154.0 установлен отдельно в игнорируемом Git каталоге `data/codex-cli`. Приложение находит эту локальную установку; на другом компьютере использует CLI из PATH. Для отладки путь можно задать через `DND_CODEX_BINARY`. Этот каталог, авторизация и настройки не входят в исходники и релиз.

Сервер работает на loopback; запросы защищены тем же токеном, что и прежний интерфейс. Игровой Codex запускается в новом временном каталоге с `--ephemeral`, `--ignore-user-config`, read-only sandbox и отключёнными shell, браузером, MCP из пользовательского конфига, приложениями, плагинами, навыками, памятью и делегированием. Включённые администратором политики остаются ограничениями CLI; совместимость сторонних конфигураций требует отдельной проверки. Неверный формат ответа или событие использования инструмента не принимаются как игровой результат.

В этом базовом прогоне было 18 вызовов: 186 612 входных и 1 758 выходных токенов по usage CLI. Это использование подписки, не долларовый расход API и не оценка оставшегося лимита. Диагностические запросы настройки в эти числа не входят.

После замера проверяющий исключён из обычного перехода героя между уже известными соседними местами: ссылки, положение и допустимость перехода полностью проверяет код. Дополнительный живой прогон:

- Переход к лесу: **14,78 с**, два вызова вместо трёх.
- Заявление «у меня якобы уже был волшебный меч, телепортируюсь»: **8,36 с**, запрос уточнения, предмет не создан, герой не перемещён.
- Итого дополнительный прогон: три вызова, 30 452 входных и 263 выходных токена.

Эти примеры подтверждают работу короткого пайплайна. Они не доказывают отсутствие галлюцинаций в длинной партии. Публичный рассказчик получает отфильтрованные знания без секретных целей NPC и скрытых фактов; смысловой корректности текста одной схемой гарантировать нельзя, реплика доступна ведущему до принятия.

## Автоматические проверки

**135 тестов прошли**, `ruff check` — без ошибок. Новый набор проверяет атомарность эффектов, повтор команды, двойной расход, сохранение созданного места, отмену с сохранением usage, фиксацию броска при повторе, отбрасывание запоздалого ответа, восстановление после перезапуска, предел попыток, отказ проверяющего и фильтрацию знаний.

Подставной CLI проверяет JSON Schema, передачу текста через stdin без shell, исключение API-ключей из окружения, ошибки входа/лимитов/формата, тайм-аут, отмену процесса и отсутствие вывода тестовых секретов. Проверена конвертация `oneOf` в поддерживаемый Codex `anyOf`; локальная строгая проверка исходной модели сохранена.

Браузерный прогон с подставным провайдером: предложение → перезагрузка страницы → принятие → проверка с физическим броском → неудача → отмена; проверена ширина 390 px. Ошибок JavaScript нет. На запущенном приложении отдельно проверены настоящий статус входа ChatGPT и доступность текстового ввода. Контрольная сумма состояния старой демопартии до и после обновления совпала.

Команды без живых запросов:

```bash
uv run --frozen pytest -q
uv run --frozen ruff check dnd_helper tests scripts
PYTHONPATH=. uv run --frozen python scripts/browser_world_check.py
```

Ограниченный живой прогон запускается вручную и расходует лимит подписки:

```bash
PYTHONPATH=. uv run --frozen python scripts/free_world_probe.py \
  --codex /path/to/codex --steps 6 --output /tmp/dnd-world-probe.json
```

## Границы этого среза

- Один герой и небольшая область; максимум 60 сущностей и 200 фактов, затем понятная остановка прототипа. Поиск и сжатие памяти для длинной игры ещё не реализованы.
- Поддержаны перемещения, создание сущностей, передача/расход предметов, урон/лечение, факты и обещания. Полный бой и произвольная редакция правил не готовы.
- Нет импорта `dnd-world@1`, редактора мира, ручного изменения операции и паузы отдельной кнопкой. При спорном предложении можно отклонить или отменить и уточнить текст; бросок после ошибки рассказчика сохраняется.
- Новый режим работает через Codex. Альтернативный API пока подключён только к прежним приключениям; его перенос на новый контракт впереди.
- Telegram и голос не подключались. Windows-сборка этой версии и вход в новый аккаунт на ноутбуке ведущего ещё не проверены. Старый опубликованный exe не содержит этот режим.
- 22–33 секунды для сложного хода заметны в игре; целевые задержки ТЗ и ресурс подписки на целую партию ещё предстоит подтвердить.
