# Тихая таверна — v0.1.0-rc.1

Первый кандидат на выпуск локального помощника ведущего настольной ролевой игры.

## Скачать и запустить на Windows

1. Скачайте **DnD-Helper-windows-x64.zip** из Assets этого выпуска.
2. Полностью распакуйте архив и откройте папку `DnD-Helper`.
3. Запустите `DnD-Helper.exe`; папка `_internal` должна оставаться рядом.
4. Начните в деморежиме без ключей либо настройте Telegram/OpenAI через «Подключения».

Установка Python, Git, Node.js и Docker для готового пакета не нужна. Исходники доступны отдельным архивом **DnD-Helper-source.zip** и в Git по тегу выпуска. SHA-256 Windows-архива находится в файле **DnD-Helper-windows-x64.zip.sha256**.

## В этой версии

- Экран ведущего, карточки персонажей, действия, броски, журнал, сохранение и отмена.
- Встроенное приключение «Сердце водокачки».
- Импорт собственных приключений из JSON: промпт для браузерного чата, проверка документа, отчёт для исправления и библиотека сценариев.
- Пример «Последний сигнал» со своими персонажами и кубиком d6.
- Подготовленные интеграции Telegram, распознавания голосовых и GPT API.

## Что ещё проверить

Это **предварительный выпуск**: нужен запуск двойным щелчком на ноутбуке ведущего с Windows 10/11 и пробная живая игра. Настоящие Telegram/OpenAI-запросы с ключами в CI не выполнялись.

Импорт поддерживает механики `declarative@1`, перечисленные в промпте. Полная произвольная редакция D&D не подключается одним текстовым описанием. Импорт сохранений пока отсутствует; восстановление работает из локальной базы.
