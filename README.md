# DnD Helper · игровая IDE ведущего

Локальное текстовое приложение для начинающего ведущего настольной игры. Единственный поддерживаемый интерфейс — `/studio`: живая модель играет мир и готовит черновик, а человек редактирует и подтверждает текст и память. Отдельный режиссёрский редактор приватно оценивает текущий черновик и может пересобрать его только по явному выбору ведущего.

Сейчас встроен лабораторный срез «Сайрус → Дом → Око». Это стенд проверки подхода; загрузка пользовательских сценариев будет спроектирована после живых прогонов.

## Запуск

Нужны Python 3.11–3.13, `uv` и официальный Codex CLI 0.154.0+ с личным входом через ChatGPT.

```bash
uv sync --frozen
uv run dnd-helper
```

Приложение откроет `http://127.0.0.1:8765/studio`. Можно указать отдельный каталог:

```bash
uv run dnd-helper --data-dir /tmp/dnd-studio
```

Рабочая игра хранится в `studio.sqlite3`. Не используйте пользовательский каталог для автоматических проверок.

## Проверка

```bash
uv run --frozen pytest -q
uv run --frozen ruff check dnd_helper tests scripts
node --check dnd_helper/static/studio.js
uv run --frozen python scripts/smoke.py
PYTHONPATH=. uv run --frozen python scripts/browser_studio_check.py
```

Живой `scripts/studio_probe.py` расходует лимит подписки; обычные тесты используют подставную модель.
