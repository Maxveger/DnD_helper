Помощник ведущего

Игроки говорят и действуют за столом. Вы получаете подсказку, выбираете реплику и подтверждаете изменения. Этот экран содержит секреты.

Подключение по подписке ChatGPT

Проверяем вход…

Выбор сохраняется только в приложении. Во время хода модель не меняется.
Как подключить на другом компьютере

Установите официальный Codex CLI и перезапустите приложение. Нажмите «Войти через ChatGPT» и завершите вход в своём аккаунте с доступом к Codex. Пароль и ключ в это приложение вводить не нужно.

Если окно входа не открылось, выполните codex login в терминале, затем «Проверить вход».

Установка Codex

Модель подсказчика выбирается на этой странице; личные настройки Codex остаются прежними. Лимит подписки проверяется в Codex; автоматического перехода на платный API нет.

Свой сценарий и журнал игры

Подготовьте мир в браузерном GPT с комплектом автора. Вставьте JSON dnd-world@1 или загрузите журнал dnd-world-log@1 для продолжения. Проверка бесплатная и локальная.


    
Сценарии dnd-adventure@1 открываются в прежнем режиме по ссылке сверху. Чужие правила не подменяются автоматически. Журнал содержит секреты ведущего; незавершённая карточка в экспорт не входит.
